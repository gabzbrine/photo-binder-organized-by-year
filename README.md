# photo-binder-organized-by-year-for-window-10
It is a photo binder organized by year for Window 10.
For use us you need: Pillow and hachoir.
For install Pillow and hachoir you can use this command "pip install Pillow hachoir"
This script is on python and the code is create by gemini 3.1.
You need to have a SOURCE (exemple: C:\Users\tete\Pictures) and a CIBLE (TARGET in english) (exemple: C:\Users\tete\PICTURES_organized_by_year)
